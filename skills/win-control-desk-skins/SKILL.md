# 皮肤制作

交付能在设置中选择的主题及所需本地素材。皮肤负责视觉，不改变应用启停、窗口身份或卡片业务行为。

## 确定项目和制作方式

- 从用户打开或指定的源码目录确认 `static/themes/`、`tools/check_project.py` 和 `ASSET_PROVENANCE.md`。安装 Skill 的目录不一定是源码目录，以下路径均相对源码根目录。
- 先阅读 `static/themes/README.md` 的主题与结构边界；制作素材包再读 `static/themes/packs/素材包制作说明.md`。只改已有主题时阅读该主题实际 manifest/CSS 和相关素材，不加载全部主题实现。
- 依据用户给出的参考图、材质、配色和目标主题推进。新增皮肤默认独立目录；用户要求修改指定皮肤时原位修改。只有缺失信息会实质改变视觉方向或覆盖范围时才询问。
- 同一布局下的配色、纸面、布料、木质等视觉优先使用现有主题包。特殊 WebGL 效果不由图片槽位自动提供，仅在用户要求时扩展，复用已有生命周期和降级逻辑。

## 建立主题包

1. 在 `static/themes/packs/` 下选未占用的目录名：小写英文、数字、短横线或下划线，以英文或数字开头，最长 59 字符。不要给正式包加前导下划线；运行时虽会忽略它，当前项目检查会拒绝非法目录。
2. 选择最接近的已有包复制：`journal` 是通用 SVG 占位框架，`papercut` 有透明纸卡与九宫格边框实作，`celadon` 有瓷面实作。不要为沿用某套材质而覆盖原包。
3. 修改 `theme.json` 的非空 `name/author/desc` 和非空 `colors` 数组。作者填实际提供者，不沿用不实署名。包 ID 由目录自动生成 `pack-目录名`，无需维护 JS 名单或复制一个固定 `id`。
4. 保留 `theme.css`、一张 `preview.webp/png/svg` 和实际引用的素材。预览按 WebP → PNG → SVG 优先选取。通用槽位保留 `@import url('../../elements.css')` 及包内素材绑定区，避免相对 URL 在共享 CSS 中解析到错误目录。
5. 定制浅色和 `:root[data-theme="dark"]` 两套语义色：背景、正文层次、边框、强调、运行、危险、警告和焦点。透明纹理可共用；不透明浅色图片需要合适的深色素材或独立背景处理，不用全局反色滤镜。

## 制作与登记素材

- 按效果实际需要制作素材，不强制填满所有槽位；不用的槽位设为 `none`，清除无效引用。尺寸、透明要求和九宫格切分见素材包制作说明。
- 优先复用用户提供或仓库已有的合法素材。需要生成位图时使用当前环境可用的图像生成能力；没有工具时说明限制，先完成可用的 CSS/SVG 部分，不声称已生成图片，也不把本 Skill 绑定到某个付费服务。
- 背景中心保持低干扰，纹理可平铺，边框中心透明，装饰保留真实 Alpha。文字、数值、状态灯、应用图标和可点击按钮仍由程序绘制，不能烘焙进整页图片。
- 素材全部本地引用，不新增 CDN、外链字体或远端追踪资源。用户私人图片、路径和生成记录在公开前按授权脱敏。
- 将新增或替换的图片、预览、字体逐文件登记到 `ASSET_PROVENANCE.md`，同一行包含路径与当前 SHA-256。记录能确认的来源、生成方式和用途；未知日期、模型、许可或版本如实标明。第三方素材按实际情况补充 `THIRD_PARTY_NOTICES.md` 和许可文件，不把设计指导 Skill 当作素材来源或官方授权。

## 不破坏原有交互

- 颜色、纹理、边框、阴影、字体和视觉动效留在主题。网格、尺寸、定位、滚动、响应式、显隐和点击区域属于结构层；纯换皮不顺手修改它们。特别不要给浮动抽屉、搜索面板等统一加 `position: relative`。
- 装饰不拦截点击，不盖住文字、焦点或滚动区域。运行、异常、禁用、选中、当前场景和待切换状态仍可区分，保留减少动态效果、提高对比和可见焦点。
- 翻面和拖拽时机复用已有主题变量；长按关闭的判定由业务层负责，不单独改变蓄力动画时长造成视觉与操作错位。
- 若确需 WebGL，复用共享表面和 DPR 限制，不逐卡创建上下文；退出主题释放画布、观察器和监听器，不支持 WebGL 或减少透明度时有 CSS/实底回退。

## 验证与交付

在源码根目录，使用已核实的 Python 3.12+ 和 Node.js：

```powershell
python tools/check_project.py --skip-tests
python tools/build_release.py --check-only
```

针对改动选择现有主题行为测试，按实际执行结果报告。若改变共享交互或生命周期，运行相应回归，不能靠删除失败测试交付。

浏览器检查优先使用 `python tools/ui_demo.py --port 9610` 的内存假数据服务。端口已占用时选另一个空闲端口，不停止未知服务；仅结束本次自己启动的演示进程。不要读取个人卡片做截图，也不要为预览换皮而修改正式配置。

检查新主题可选、刷新持久化、浅/深色、各页导航、卡片大小、390px 窄屏、菜单/抽屉/卡片背面、焦点、告警及禁用状态；切回原主题确认资源释放。新主题的动效/材质另核对减少动态效果、对比度和 WebGL 回退。用户限制验证范围或环境缺浏览器时明确列为未验证，不把静态检查当作视觉验收。

交付主题名称和目录、预览、素材来源、检查结果及未完成项；未经请求不改变用户当前使用的皮肤、不安装全局组件、不发布仓库。
