# 剪纸 · 手账素材与生图提示词

`pack-papercut` 使用纸卡、折角、纸条、回形针、长尾夹和图钉构成手账外观。文字、应用图标、状态及交互由页面绘制，图片只承担纸面和装饰。素材来自 Imagegen，经过裁切、去底和缩放；逐文件来源与指纹见根目录 `ASSET_PROVENANCE.md`。

## 素材处理

1. 根据参考图重建没有文字、图标和按钮的独立空白纸卡、纸条或装饰。
2. 检查实际像素尺寸和 Alpha 通道。画在 RGB 图片里的棋盘格不是真透明；无法生成透明背景时，可生成与主体颜色不重叠的纯色背景，再由支持去底的工具处理。
3. 裁切外部留白、清理背景并保留纸面像素；在有色背景上检查毛边、孔洞和内部透明空隙。
4. 从纸卡中心选取低对比纹理，拼接后检查接缝，再用作可平铺底材。
5. 图片输出到包内的 `assets/`，检查对应 CSS 路径、预览与素材台账。生成工具的目标尺寸不保证实际输出尺寸，应以文件为准。

纸卡九宫格参数为上 80、右 120、下 60、左 60 源像素，对应页面 24、36、18、18 CSS px。九宫格只作用于纸面伪元素，不能把翻面菜单、焦点环或点击区一起裁切。打孔纸卡使用自己的切分参数，以 `theme.css` 为准。

深色模式压暗纸面，文字和应用图标不经过该滤镜。高对比模式使用实底及清晰边线，小窗口隐藏部分角饰。

## 生图提示词示例

每次附上同一风格参考图，分别生成单个元素；裁切、去底、缩放、命名和接入由制作工具完成。

### 空白纸卡

> 请以附上的手账界面图为风格参考，提取并重建一张独立的空白纸卡。保留米白纸纤维、自然撕边、右上角折角和左下角轻微卷边。去掉所有文字、应用图标、按钮、状态灯、数字、回形针和其他界面内容，补齐干净纸面。正视俯拍，无透视、无旋转；横向约 3:2，目标 1536 × 1024 像素，主体占画面约 90%，四周完整留边，中央至少 80% 安静留白。输出真实透明 PNG，不要画棋盘格。如果工具不能输出真实透明底，外部背景使用均匀纯品红色 #ff00ff，纸内不得出现品红色，背景不加投影。一张图只画一张纸卡，不画整套 UI，不加文字和水印。

### 空白纸条

> 请沿用参考图的纸张材质，重建一根空白纸条。米白纸纤维、细小不规则撕边、轻微纸边厚度，正面视角，无透视、无旋转。去掉全部文字和图标，中央安静留白。横向约 4:1，目标 1536 × 384 像素，主体四周完整留边。输出真实透明 PNG，不画棋盘格；若工具不能输出真实透明底，外部使用均匀纯品红 #ff00ff，纸内不得出现该颜色，背景不加投影。只要一根空白纸条，不含按钮文字、完整界面或其他装饰。

## 复用为其他主题

复制完整 `papercut` 目录到新的合法包名，修改 `theme.json` 的名称、作者、说明和色板，再替换所需素材与 `theme.css` 配色。保持图片尺寸与折角范围时可复用九宫格参数；形状明显改变时应重新调整切分。

季节风格可分别使用浅绿/淡粉、浅蓝/米白、麦黄/赭色、雾白/灰蓝。花枝、雪花等不要侵入正文区域，不把动态文字、应用图标或选中状态烘焙进图片。

完成后依照主题制作 Skill 检查素材指纹、资源引用、浅深色、窄屏、翻面、键盘焦点、主题切换和辅助功能。实际结果按验证环境记录。
