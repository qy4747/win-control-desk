# Win Control Desk 素材主题包制作规格

主题包通过设置中的主题选择器加载。“手账素材”是可运行的 SVG 占位示例，用于展示槽位、尺寸和交互。

“剪纸 · 手账”使用重建并裁切的纸卡、纸条，支持真实透明轮廓；制作同类型主题时可参考 [剪纸素材与提示词](papercut/实作记录与生图提示词.md) 并复制完整 `papercut` 目录。下方为 `journal` 占位包的槽位规格，按需要选择素材，不要求每套主题生成十二张图片。

## 新增主题的方式

1. 复制整个 `journal` 文件夹到同层，例如 `forest`、`kraft`、`blueprint`。
2. 修改新文件夹的 `theme.json` 中 `name`、`desc`、`colors`。
3. 替换 `assets` 中的素材；如果从示例 SVG 换成 PNG/WebP，在 `theme.css` 对应 `url(...)` 中改扩展名。
4. 修改 `theme.css` 的浅色、深色配色变量。保留 `@import url('../../elements.css')` 和文件末尾的素材绑定区（复制即可，不需要修改选择器）。
5. 刷新控制台，在设置中选择新主题。自动注册为 `pack-forest` 等，无需改 JS、业务组件或手工维护主题名单。

文件夹名限小写英文、数字、短横线、下划线，以英文或数字开头，最长 59 个字符。以 `_` 开头的目录不会注册，也不能通过项目的有效主题包检查。元数据不需要 `id`，避免复制时撞名。

```text
static/themes/
  elements.css                    # 共用素材映射与状态样式，不随包修改
  packs/
    journal/                      # 复制这整个文件夹
      theme.json                  # 名称、说明、预览色
      theme.css                   # 图片路径、配色、圆角和阴影参数
      preview.svg                 # 可替换为 preview.webp 或 preview.png
      assets/
        background.svg
        chrome.svg
        panel.svg
        card.svg
        control.svg
        frame.svg
        label-frame.svg
        decor-a.svg
        decor-b.svg
        decor-c.svg
        corner.svg
```

同一包内保留一张预览图即可；同时存在时按 WebP → PNG → SVG 选择。素材不应引用外网资源。所有动态文字、应用图标、状态灯、数字和点击区域仍由程序绘制。

## 给生图工具的元素清单

表中的像素是**交付图片尺寸**，不是界面控件固定大小。卡片、面板、按钮仍按窗口和内容自动变化。

| 文件名主体 | 交付尺寸 px | 实际使用 | 透明要求 / 构图要求 |
|---|---:|---|---|
| `background` | **2560 × 1440**；4K 可用 3840 × 2160 | 整页背景，居中铺满、超出裁切 | 可不透明；中央 70% 保持安静，重点物体放四周；不同屏幕会裁掉边缘 |
| `chrome` | **512 × 512** | 侧栏、顶栏的共用底材；按 256 CSS px 平铺 | 无缝纹理；建议透明纤维/颗粒，底色由代码控制 |
| `panel` | **512 × 512** | 设置、日志、搜索结果、表格、场景栏、弹窗底材 | 无缝纹理、低对比，不带边框或强光斑 |
| `card` | **512 × 512** | 应用卡片、文件夹卡片底材 | 无缝纸面纹理；文字区域不画图案、折痕或污渍 |
| `control` | **512 × 512** | 按钮、导航选项、分类标签、场景按钮的表面纹理 | 透明低对比颗粒；选中、危险、禁用颜色由代码控制 |
| `frame` | **512 × 512** | 卡片四边与四角的装饰边框 | **透明中心**；四边各 64 px 为边框带；九宫格切分，界面边框厚度 8 CSS px |
| `label-frame` | **384 × 128** | 按钮与标签的装饰轮廓 | **透明中心**；四边各 24 px 为边框带；九宫格切分，显示厚度 3 CSS px |
| `decor-a` | **256 × 128** | 卡片右上角，循环样式 A；默认显示 48 × 24 CSS px | 透明背景；横向胶带、封条等，四周留约 8% 空白 |
| `decor-b` | **128 × 256** | 卡片右上角，循环样式 B；默认显示 18 × 36 CSS px | 透明背景；竖向回形针、小夹子等，四周留约 8% 空白 |
| `decor-c` | **128 × 128** | 卡片右上角，循环样式 C；默认显示 24 × 24 CSS px | 透明背景；图钉、印章、角贴等，四周留约 8% 空白 |
| `corner` | **512 × 512** | 导航底部角饰，显示 80 × 80 CSS px | 透明背景；叶片、折纸等，主物体靠右下；避免大面积深色遮住信息 |
| `preview` | **640 × 400** | 设置中的主题缩略图，居中裁切 | 可不透明，表现整体配色与材质即可；真实操作时不使用此图 |

**首批建议先做 5 张底材 + 2 张边框。** 装饰与预览可以后补；无需某个槽位时，在 `theme.css` 将对应变量设成 `none`，不要留失效图片路径。

## 生图与交付约定

- 一张图只包含一个元素；不要把整页 UI、按钮文案或应用图标画进素材。
- 背景使用 WebP/JPEG；透明元素用 PNG/WebP。不要用“棋盘格背景”假装透明，需要实际 Alpha 通道。
- 纹理采用正视、无透视、四边无缝拼接；明暗起伏要轻，避免平铺后出现规律的大斑块。
- 边框是透明中心的独立描边/纸边装饰，不是整张卡片截图。四个角放在切分角区内，四边中段应能拉长；不要在边框里带文字、图标、胶带或回形针。
- 边框可以做毛边、压线或缝线，但不会裁切卡片内容。需要大幅撕裂、镂空或完全不同的卡片轮廓时，需要再扩展形状规则。
- 胶带、夹子、图钉分别出图，不要与卡片合并。默认 A/B/C 循环分配，无随机漂移；不会拦截点击，窗口 ≤600 px 时隐藏卡片和页角装饰。
- 普通底材推荐每张 ≤300 KB，装饰 ≤150 KB，背景 ≤2 MB；这是性能建议，不是导入限制。
- 阴影由 CSS 统一绘制，底材与边框不要烘焙大面积投影。立体夹子/图钉可保留很轻的自阴影。

可直接给 Chat 的单图提示词模板：

> 为桌面控制台制作「[主题名称]」的独立 [元素名] 素材，尺寸 [宽 × 高] px。[透明或不透明要求]。[无缝纹理 / 九宫格边框 / 独立装饰的要求]。正面视角，不包含界面、文字、数字、Logo 或应用图标，不加水印，不组合其他元素。整体配色：[色板]；材质：[描述]；光线柔和均匀，细节不过度抢眼。

## 素材与组件的边界

| 框架负责 | 主题包负责 |
|---|---|
| 网格、卡片尺寸、响应式布局、滚动 | 背景、表面纹理、边框、角饰 |
| 应用启停、菜单、翻面、拖拽、键盘焦点 | 常规/悬浮阴影、圆角、字体变量 |
| 选中、禁用、报错、运行中等状态判定 | `accent/green/red/amber` 等语义色 |
| 状态文字、数字、应用图标 | 浅色与深色两套配色，必要时两套图片 |

同一结构下的手账、木质、布料、蓝图、金属等材质主题可以复用。完全不同的信息布局或 Apple WebGL 光学材质不由这套图片槽位自动生成。

## 配色与深色模式

`theme.css` 已给出浅/深两组色板；保留 `--room`、`--card`、`--card-2`、`--ink` 到 `--ink-4`、`--line`、`--line-2`、`--accent`、`--on-accent`、`--green`、`--red`、`--amber`、`--purple` 的语义。

透明纹理可直接复用两种模式。不透明浅色图片不会自动变暗：须在 `:root[data-theme="dark"]` 中为相同图片变量指定深色素材，例如 `--element-card: url('./assets/card-dark.webp')`。深色素材尺寸与浅色一致。不使用反色滤镜，以免改变装饰和应用图标颜色。

卡片宽度由原有小/中/大设置控制，不能把整张纸片强行拉伸当卡片。纹理平铺、边框九宫格、装饰等比缩放各自独立，标题长短和窗口变化不会拉扁回形针或图钉。

## 装包后的核对

切换新主题 → 刷新确认保留 → 依次打开六个页面 → 查看菜单和卡片背面 → 切换浅/深色 → 测试小/中/大卡片和窄窗口 → 切回极简与 Apple。确认文字清楚、边框不遮字、装饰不挡按钮、无失效图片。
