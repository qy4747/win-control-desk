# Windows 使用说明

总控台使用 Python 标准库、原生网页和 JSON 配置，无需数据库或系统服务安装。Windows 是主要支持平台；macOS 提供兼容启动入口，Windows 原生采集与通知仅在 Windows 使用。

## 日常入口

- 启动台长期保存应用/服务和批处理卡片，状态变化不改变排序。添加菜单支持手动配置及“从运行中发现”；不扫描开始菜单。
- 发现默认展示当前用户的窗口应用与监听服务，可展开其他进程。展示路径、命令、PID、端口后再明确认领；没有可靠启动命令可以保存观察卡片，补齐配置前禁用启动/重启。
- 运行状态由 token 或已验证的 PID、创建时间、路径及当前用户确认。启用“跟随应用重启”后，按可执行文件、启动参数摘要匹配独立根进程；服务/脚本保留启动参数、项目入口等身份约束；可解析的绝对服务入口不因启动器工作目录变化而误失联。唯一匹配才关联新 PID，多个候选或已属于其他卡片时停止自动关联并提示选择；不按名称或端口单独认领。详情可关闭自动识别，修改启动配置后需重新确认规则。
- 首页保留左侧导航、搜索、精简性能总览、场景选择、分类标签和固定卡片。服务的业务端口显示在固定右侧按钮，命令和完整探测信息放入详情；右上角文字标记应用 / Shell（一次性脚本任务）/ 服务。未配置探测不代表健康，数据缺失显示未知。CPU 为全机归一化百分比；进程 I/O 与整机物理磁盘写入分别计算。
- 应用异常通过卡片角标进入详情；系统异常在性能总览旁显示。卡片详情居中展开，二级编辑退出后返回上一层并保留父层草稿。基线、通知状态、卡片尺寸和预设编辑在设置中心，不重复展示首页概览。卡片尺寸为浏览器本地小/中/大三档。
- 卡片顶部左侧固定“关闭 / 打开”；右侧普通应用为“前台”，服务为端口号按钮（点击打开网页）。停止后前台与端口按钮置灰，端口未就绪或未配置时也置灰；下方两个软件专用按钮由“翻面 → 编辑卡片按钮”设置，其余放背面。目录动作默认始终可用，依赖应用的命令动作设为运行中，状态不符时置灰；按钮的显示时机可独立设置。恢复默认不删除自定义动作。

## 操作与退出

Windows 桌面卡片默认提取已配置 EXE 的图标并缓存为 PNG，已有自定义图片优先；解释器类程序不提取通用图标，Web 服务可上传项目 logo。图标提取不启动应用。

详情可保存命令、回环 HTTP API 或网页动作，并限定始终/运行中/停止时可用。命令使用现有 CMD/PowerShell；HTTP 支持方法、头、正文与超时，拒绝远程地址和重定向，不将认证头或响应正文写入事件。

### 相关位置与窗口

- 在卡片详情的“相关位置”添加名称、文件/目录绝对路径和打开方式，点击“保存详情设置”。支持资源管理器、终端、编辑器；同一路径可保存为多个不同入口，预设命令继续使用“自定义操作”。
- 资源管理器打开目录或选中文件；终端在目录（文件则在其父目录）打开。Windows 使用交互 PowerShell；默认编辑器为记事本，可填写 Code.exe 等编辑器的绝对路径。打开目录时必须指定支持目录的编辑器。macOS 使用 Finder、Terminal 和 TextEdit。
- 位置默认始终可用，不依赖卡片运行状态；可在“编辑卡片按钮”放到正面，其余自动放到背面。保存按钮布局时，位置入口建议保留“始终”。新建位置保存后才能打开。
- 打开位置只发出独立启动请求，不等待编辑器或终端退出，不进入命令动作的超时/结束进程树流程。提示成功表示启动请求已发出，目标应用自身的后续错误仍由它显示。
- Windows 详情中的“选择 / 更换窗口”列出当前用户可访问的窗口，选中后可通过“前台”唤起。前台切换被 Windows 拒绝时显示提示，不报告成功。
- GUI 与 TUI 均手动选择实际窗口；TUI 应选择宿主终端。关联窗口不定位终端中的单个标签，不改变卡片的进程认领或停止范围。
- 窗口关联校验句柄、PID、进程创建时间、路径、用户及窗口标记；失效后按窗口类、工具窗口属性重新匹配，GUI 限定在当前已验证进程树内，外部终端/浏览器窗口还要求原窗口标题一致。多个候选需选择，不按面积猜主窗口。窗口操作仅支持 Windows，不能控制权限更高或不可访问的窗口。

正常停止优先执行配置的退出动作，否则尝试窗口正常关闭。后台服务应配置它自身支持的退出 API/命令。停止超时只报告失败并保留身份；强制结束必须单独确认。重启先验证旧实例已退出，身份未知时停止操作。

明确确认“强制结束”后，Windows 会短暂暂停已按身份核实的实例并刷新当前卡片进程边界，防止启动期间生成的后代漏停；独立子卡片不纳入结束范围。准备失败会尝试恢复本次暂停，不自动提权；原生暂停接口或权限不可用时拒绝执行。普通正常关闭不走这一暂停流程。

关闭网页后监控继续运行；设置中心的“停止总控台”控制后台本身，被管理应用继续运行。不会设置开机启动、安装系统服务，也不会自动拉起、重启或杀掉异常应用。

## 规则与通知

系统默认 CPU/内存超过 90% 持续 60 秒、固定磁盘剩余空间低于 10% 持续 60 秒提醒。阈值、持续时间、检查间隔、恢复阈值及静音均可编辑。写入速率/区间增量、指定目录大小/增长必须自行配置；不默认扫描目录、不自动学习基线。

长期服务在启动或明确认领后建立“应运行”预期；通过控制台或预设主动停止会解除。桌面应用普通关闭不报警，有已知失败退出码才提醒；批处理成功、exit 130 取消和主动中止不报警。应用资源阈值默认关闭，可逐卡覆盖退出策略、启动宽限、CPU/内存阈值及静音。

端口与 HTTP 在运行且过了默认 30 秒宽限后，连续失败三次进入异常、连续成功两次恢复；停止的应用不因端口/接口离线报警。首次导入的无效配置只展示检查结果，后续由有效变失效才提醒。采集失败不会当作退出或异常恢复。

异常详情可“忽略本次异常”：取消首页强调及本次恢复通知，详情仍保留；忽略状态写入 JSON，跨页面和后台重启保持。确认恢复后自动解除忽略，再次发生正常提醒。长期静音在对应规则中设置，仍保留异常状态与事件。

每个异常进入与恢复各记录一次，静音只关闭通知，不丢事件。事件写入日志目录 `events.jsonl`，5 MB 上限、两份轮转，页面最多读取最近 300 条。Windows 通知身份为用户级 `Cddeck.LocalOps`，注册显示名和开始菜单中的 `Cddeck 总控台.lnk`（不在启动目录、不设置自启动），不修改系统通知权限。此快捷方式用于满足 [Windows 桌面通知身份要求](https://learn.microsoft.com/en-us/windows/win32/shell/enable-desktop-toast-with-appusermodelid)。首次发送前可能显示“待首次通知验证”；系统禁用/不可用时，设置中心显示状态，事件仍保留。浏览器任务完成通知独立设置。

## 采样与轻量边界

页面活跃时每 2 秒采样进程/资源，无活跃页面时每 10 秒；多个页面共享一次扫描。HTTP 默认每 10 秒、磁盘容量每 60 秒、指定目录默认每 15 分钟。目录仅检查明确指定的本地子目录，不跟随链接/联接点；检查超时或失败不发布部分大小用于告警。

整卡显存读取适配器级专用/共享计数器；单进程使用 Windows 原生 `D3DKMTQueryVideoMemoryInfo` 的 LOCAL 段 CurrentUsage，按已关联应用的进程树汇总。任一适配器查询失败时不发布部分合计，显示暂无数据。资源榜按应用汇总、监听进程按 PID 去重；顶部 CPU、内存、显存分别悬浮展示各自 TOP 3。容量未知时没有百分比告警。项目不提供网络占用告警、网页内嵌交互 TUI、终端标签精确定位、完整文件管理器、日历、下载状态和长期性能历史。

## 手动模式

设置中心保存每张选中卡片的启动/停止/保持不变和基线覆盖。首页点选场景只改变选择，点击右侧“切换场景”后提示保存工作并展示清单，再确认才执行。先停止，再按保存顺序启动；已经满足的目标跳过。HTTP、端口、受控进程按配置决定就绪，任务等待本次结果。场景单项失败后停止后续切换；应用包才继续其他独立项。取消只停止后续操作，不回滚已执行动作，不持续强制维持应用运行。

## 扩展接口与验证

接口使用回环访问保护与每应用操作锁：

| 路径 | 用途 |
| --- | --- |
| `GET /api/ops/discover?all=1` | 当前用户运行对象（省略 all 仅窗口/监听） |
| `POST /api/ops/discover/import` | 创建/重新关联精确运行实例 |
| `POST /api/ops/action` | 执行指定卡片动作 |
| `GET /api/ops/windows` | 当前用户可关联窗口，返回句柄和进程身份 |
| `POST /api/ops/window/bind` | `{appId, window}` 关联明确选择的窗口；`window:null` 解除 |
| `POST /api/ops/window` | `{appId, operation: "focus"}` 唤起已验证窗口；服务卡片使用对应网页入口 |
| `POST /api/ops/instance` | `{appId, enabled}` 从当前已关联实例生成稳定规则，或关闭自动识别 |
| `POST /api/ops/force` | 明确 `confirmed:true` 后强制结束 |
| `POST /api/ops/alerts/ignore` | 使用 `key` 与 `incident` 忽略当前这一轮异常，拒绝过期标识 |
| `GET /api/ops/config` / `GET /api/ops/events` | 基础规则、预设配置及事件 |
| `POST /api/ops/rules` / `POST /api/ops/presets` | 保存已校验的规则/预设 |
| `POST /api/ops/presets/run` / `cancel` | 执行/取消；结果在共享状态 `presetRun` |

`/api/state` 读取后台快照，包含 `system/alerts/events/notificationStatus/presetRun/sampledAt/collectorDurationMs`，应用包含 `resources/statusKnown/probeState/associationState`。

配置 schema 为 **8**，保存卡片按钮、忽略状态、临时基线、窗口关联、相关位置、实例匹配以及文件夹/搜索设置。配置迁移保留备份，超出程序支持范围的 schema 拒绝写入。窗口关联只能通过专用接口保存，普通卡片更新不能直接提交窗口身份。

`instanceMatch` 由服务器从已验证的运行实例生成，身份信息可读时导入卡片默认启用。窗口绑定保存稳定匹配特征；启动参数使用 SHA-256 摘要。路径、有效参数或服务入口发生变化时需要重新确认关联。

首页“当前生效”来自 `activePreset`，表示已启用的场景基线；“待切换”仅是页面选择，确认后才执行。启停的成功、失败或取消另看执行结果。卡片的运行／配置错误与未忽略告警分别使用 `has-error`、`has-alert`，忽略告警不清除真实错误态。

运行 `py -3.12 tools/check_project.py` 完整检查。`py -3.12 tools/measure_idle.py --seconds 1800 --output tmp/idle-acceptance.json` 使用独立临时配置测量后台与辅助进程，记录全机归一化 CPU、工作集及采集耗时，并发出一次标明验收的通知；不会控制个人应用。参考目标为平均 CPU ≤1%、工作集 ≤150 MiB，是否达到应以实际记录为准，内存趋势与浏览器占用单独检查。自动检查与真实 Windows 桌面/通知验收分别记录。
