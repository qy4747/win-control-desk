# Windows 使用说明

安装、启动和数据目录见 [README](../README.md)。Windows 是主要验收平台，macOS 保留兼容入口。

## 添加与识别应用

在启动台“添加”中手动配置应用、服务或一次性脚本任务，也可选择“从运行中发现”。发现列表默认展示当前用户的窗口应用与监听服务；核对路径、命令、PID 和端口后保存卡片。

没有可靠启动命令时可以保存观察卡片，补齐命令后才能启动或重启。桌面卡片自动提取 EXE 图标，已有自定义图片优先；Web 服务可上传项目图标。

“跟随应用重启”使用可执行文件和启动参数等身份特征寻找新实例。唯一匹配时自动关联，多个候选时提示选择。修改启动配置后需重新确认规则，详情中可关闭自动识别。

## 卡片与按钮

- 左上角为打开/关闭；右侧为普通应用的“前台”或服务的端口按钮。应用停止、状态未知或入口不可用时，相关按钮置灰。
- 正面下方最多两个专用按钮，其余放在背面，通过“翻面 → 编辑卡片按钮”设置。
- 自定义动作支持 CMD/PowerShell 命令、回环 HTTP API 和网页；可设置始终、运行中或停止时可用。
- 分类、搜索和运行状态变化不改变已保存排序。卡片尺寸可在设置中选择小、中、大。
- 异常角标打开详情；退出二级编辑时返回上一层并保留草稿。

## 相关位置与窗口

在卡片详情的“相关位置”添加名称、文件/目录绝对路径和打开方式，再保存。支持资源管理器、终端和编辑器；同一路径可保存为多个入口。终端在目录或文件的父目录打开，编辑器默认为记事本；打开目录需选择支持目录的编辑器。

位置默认始终可用，可放到卡片正面。成功提示表示启动请求已发出。

“选择 / 更换窗口”可关联当前用户可访问的 Windows 窗口，再通过“前台”唤起。TUI 应选择宿主终端；窗口关联不定位单个终端标签，也不改变卡片的进程管理范围。关联失效或候选不唯一时重新选择，权限更高或不可访问的窗口无法控制。

## 关闭与重启

正常关闭优先使用配置的退出动作，其次尝试窗口关闭。后台服务需配置自身支持的退出 API 或命令。停止失败会保留管理状态，强制结束需单独确认；重启会先确认旧实例已退出。

强制结束只针对已验证的卡片实例及其进程边界，排除独立子卡片；权限或身份准备失败时会拒绝执行。

关闭网页后后台监控继续运行。“停止总控台”仅停止后台自身，受管应用继续运行。异常提醒不会自动重启或结束应用。

## 场景与应用包

在设置中保存场景，为选中卡片指定启动、停止或保持不变，以及需要覆盖的基线。首页点选场景后，点击“切换场景”，检查操作清单并确认执行。

场景先停止、再按顺序启动，已满足的目标跳过。服务按已配置的 HTTP、端口或进程状态判断就绪，任务等待本次结果。

**场景单项失败后停止后续切换；应用包继续其他独立项。** 取消只停止后续操作，已执行的动作保留。首页“当前生效”表示场景基线，“待切换”表示页面选择，启停结果在执行记录中查看。

## 监控与通知

系统默认在 CPU/内存超过 90% 持续 60 秒，或固定磁盘剩余空间低于 10% 持续 60 秒时提醒。阈值、持续时间、检查间隔、恢复阈值和静音均可编辑。写入速率、区间增量、指定目录大小/增长需自行配置。

长期服务在启动或认领后建立“应运行”预期，主动停止会解除。桌面应用普通关闭不报警，已知失败退出才提醒；任务成功、exit 130 取消和主动中止不报警。应用资源阈值默认关闭，可逐卡设置。

端口与 HTTP 在默认 30 秒启动宽限后，连续失败三次进入异常、连续成功两次恢复。采集失败显示未知，停止的应用不因接口离线报警。

“忽略本次异常”取消本轮首页强调和恢复通知，详情保留，恢复后自动解除；长期静音在规则中设置。异常进入与恢复各记录一次，静音不影响事件记录。

Windows 通知使用用户级 `Cddeck 总控台.lnk` 身份快捷方式，不设置自启动。通知状态在设置中心查看，系统禁用通知时事件仍保留。事件位于日志目录的 `events.jsonl`，上限 5 MB、保留两份轮转；页面最多读取最近 300 条。浏览器任务完成通知独立设置。

## 采样与文件功能

页面活跃时进程/资源每 2 秒采样，无活跃页面时每 10 秒，多个页面共享扫描。HTTP 默认每 10 秒、磁盘容量每 60 秒、指定目录每 15 分钟检查。目录检查仅覆盖指定本地子目录，不跟随链接或联接点。

CPU 按全机归一化；进程 I/O 与物理磁盘写入分别统计。应用资源按已关联进程树汇总，数据不完整时显示暂无数据。容量未知时不触发百分比告警。

文件夹收藏可分组和复制路径。Everything CLI 搜索与 QuickLook 预览需另行安装配置；搜索按提交、排序或翻页执行。
