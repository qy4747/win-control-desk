# UI 演示与验收

运行 `py -3.12 tools/ui_demo.py --port 9610`，打开 [演示页面](http://127.0.0.1:9610/)。

演示使用当前 `static/` 页面和独立的内存假数据服务，不读取个人配置或操作真实应用。“重置演示”或重启服务可恢复初始样例。

## 可检查内容

- 12 张示例卡片：服务、桌面应用、任务、运行/停止、配置错误、端口冲突、告警和待确认状态。
- 搜索、分类、主题、三档尺寸、排序、自定义按钮、详情及子层返回。
- 卡片正面最多两个专用动作，其余在背面。聚焦卡片后，空格抓取、方向键移动、空格确认、Esc 取消；应用与任务在各自分区内排序。
- 场景选择、确认、逐项进度、结果和取消；“部分失败验收”展示失败与跳过。
- 告警忽略、事件、日志、服务/端口列表、设置、基线与预设编辑。
- 添加、编辑、删除及发现卡片；文件选择和项目识别返回虚构路径。
- 「＋ 添加 → 从运行中发现」默认只显示未添加的程序，摘要列出未添加、可能对应未关联卡片和已有卡片的数量。勾选后「复制给 AI」写入剪贴板（被拒绝时显示可复制文本），说明只含 PID、创建时间、EXE、接入入口和边界，末尾留给用户写需求。
- 图标总览：点顶栏「图标总览」或按 Ctrl/⌘+Shift+G，再点一次复用同一窗口，也可直接打开 `/glance`。按 / 搜索，方向键选择，Enter 启动或唤到前台；右键或 Shift+F10 打开菜单，「在总控台中显示」切回启动台并聚焦对应卡片。最小化小窗停止请求，恢复后立即刷新。
- 日志中心（Alt+5）：按占用、增长、错误排序；「配置失效样例」显示增长和空字节警告。打开一行后可勾「仅看错误行」，搜索并按 Enter 定位高亮，Esc 返回。离开日志中心后不再请求摘要。
- 键盘：焦点不在输入框时按 ? 显示帮助，Alt+1…6 按左侧导航顺序切换；浮层内 Tab 循环，Esc 关闭并恢复焦点。
- 底部“采集不可用”“空数据”和“完整样例”用于切换展示状态，“重置演示”恢复初始数据。

## 验证范围

打开网页、目录、外链，以及图标上传、后台重启和退出均为模拟。实际资源采集、通知、进程身份、健康探测和应用启停需另做真实环境验收，见 [发布核对表](../RELEASE_CHECKLIST.md)。
