# UI 假数据验收

运行 `py -3.12 tools/ui_demo.py --port 9610`，打开 http://127.0.0.1:9610/。
此入口直接使用当前 `static/` 页面，但所有 API 都由独立模拟器处理，不导入生产后端，不读取生产配置、扫描进程、执行命令或请求应用接口。修改仅保留在模拟器内存中；底部“重置演示”恢复全部样例，重启模拟器也会重置。

## 可验收内容

- 首页 12 张固定卡片：服务、桌面应用、运行／停止、HTTP 异常、资源告警、端口冲突、配置失效、观察卡片、待确认、任务成功／失败／执行中。
- 搜索、分类标签、三档尺寸、明暗主题、卡片排序、主按钮／更多操作、自定义动作、按钮编辑、详情与子层返回。
- 卡片顶部是打开/关闭与前台/网页入口，下方最多两个专用动作，其余放在背面。左上手柄可拖动；聚焦卡片后空格抓取、方向键移动、空格确认、Esc 取消。应用与任务各自在所属分区内排序，筛选不会改变已保存顺序。
- 场景当前／待切换直接标记在场景按钮上；执行时显示逐项进度，成功提示约 3 秒后收为“结果”，失败提示保留，可点开查看。
- 系统异常和应用异常可忽略；端口冲突与配置错误保持原有错误态。事件和示例日志仍可查看。
- 日常／工作／游戏场景，以及“部分失败验收”。点选不执行，确认后每项模拟 3 秒，可看到等待、执行、成功、失败和跳过，也可取消后续操作。
- 服务与端口页面含关联服务、外部服务、后台、隐藏和关注进程样例；日志中心、设置中心、基线规则和预设编辑可操作。
- 添加、删除、编辑、发现并加入卡片只改变演示数据；文件选择和项目识别返回虚构路径，不弹系统文件框。
- 底部可切换“采集不可用”“空数据”，检查未知态、通知不可用和空列表；“完整样例”恢复展示当前内存数据，“重置演示”恢复初始状态。

## 模拟边界

Web／目录／外链打开仅提示，不导航到真实应用；图标上传、后台重启和退出显示模拟限制。性能数值固定、告警预置，不验证实际采集、Windows 通知、进程身份、健康探测及系统控制。正常关闭在模拟中即时完成，不代表真实程序的退出速度。
